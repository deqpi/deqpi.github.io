Version 1.3.0 Changelog

Released on October 17, 2025

Added

  • Added a visual filtering menu; you no longer need to use a text editor to add games to the filter or exclusion list.
  • Added Performance Monitor, which allows you to check the plugin impact on your computer performance.
  • Added translations for 25 new languages and 3 regional variants.
  • Added a changelog panel, which can be opened by clicking the version number.
  • Added Strict Mode for lists.
  • Added dontFilterNameContains option for lists as a replacement for excluded from the previous JSON version.
  • Added dontFilterNameMatches option for lists.
  • Added dontFilterPlaceIDMatches option for lists.
  • Added filterNameContains option for lists as a replacement for marked from the previous JSON version.
  • Added filterNameMatches option for lists.
  • Added filterPlaceIdMatch option for lists.
  • Added native ARIA support for most elements; voice assistants (e.g. Narrator, Orca, VoiceOver) will activate automatically.

Improved

  • Switched list format from JSON to more user-friendly YAML.
  • Refined panel appearance with an updated color palette.
  • Improved extension security and overall stability.
  • Improved overall UI responsiveness and performance.
  • Significantly increased list filtering speed.
  • Reduced idle-time operations and fixed multiple resource leaks.

Fixes

  • Fixed an issue with an outdated version being displayed in the panel; the version now always matches the downloaded plugin version.
  • Fixed incorrect tile highlighting on the Home and Charts pages.
  • Fixed an issue where disabling basic_list would automatically reactivate it upon page refresh.

List

  • The base list has been updated from September 30, 2025, to October 17, 2025.
