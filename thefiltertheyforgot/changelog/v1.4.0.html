Version 1.4.0 Changelog

Released on November 17, 2025

Added

  • Added data origin selection, between the original page (downloaded from the roblox server) and the local one (elements already visible on the page), with an option to connect both.
  • Added option to filter lists by original page description.
  • Added "Select your list" choice memory to simplify the creation of large lists.
  • Added lazy loading for the settings repository; after 10000 entries per load, a "Continue rendering" button will appear to prevent freezing on very large lists.
  • Added a button to create new lists directly from the repository view.
  • Added real-time color preview when changing highlight color, allowing more precise adjustments.
  • Added normalized cache for previously processed titles to reduce CPU load by distributing tasks to RAM (cache resets on page refresh and does not occupy disk space).
  • Added native Light Mode (based on browser preferences).
  • Added native High Contrast Mode (based on browser preferences).
  • Added native Reduced Motion Mode for users sensitive to animations (based on browser preferences).
  • Added Shift+Click shortcut for quick word removal in the repository.
  • Added sticky header to the repository to improve navigation in large lists.
  • Added ARIA coverage improvements; voice assistants now announce filtering results and UI feedback.

Improved

  • Completely re-architected filtering engine, achieving 60-73% efficiency gains across varying filter states.
  • Changed the exported list format from folders to ZIP archives. (You can convert your old exported lists here.)
  • Improved overall UI performance and responsiveness.
  • Improved user feedback for list operations (extension will now notify when items are added or removed).
  • Improved performance statistics handling and reduced risk of memory leaks.
  • Improved translation coverage and refined phrasing to prevent layout glitches caused by text length.
  • Improved performance monitor readability and added RAM usage info for cache, along with a guide on interpreting results.
  • Improved security through multiple internal fixes and better stability.
  • Adjusted extension logo to better match the current UI theme.

Fixes

  • Fixed an issue where rating filtering could still check tiles even when disabled.
  • Fixed incorrect tile highlighting on language-prefixed pages (e.g. /de/home, /es/charts).
  • Fixed a bug where the visual menu button would overlap with the category dropdowns in the charts page.
  • Fixed several minor translation inconsistencies.

List

  • The base list has been updated from October 17, 2025, to November 17, 2025.
