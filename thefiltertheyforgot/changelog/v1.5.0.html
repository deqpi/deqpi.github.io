Version 1.5.0 [Final Release] Changelog

Released on December 16, 2025

Added

  • Added Romanian, Serbian, Persian, Swedish, Norwegian, and Mongolian languages.
  • Added Canadian English and Canadian French dialect.

Improved

  • Improved the appearance of some UI elements.
  • The default list and minimum rating will no longer be automatically enabled on first use to avoid confusing new users.

Fixes

  • Resolved a race condition in the default page function that prevented the original title from being downloaded.
  • Fixed an issue where disabling the list might not reset the tile to hidden until the page was refreshed.
