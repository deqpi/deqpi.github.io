Data Collection

This extension may collect and store the following data locally on your device:

Automatically Collected Data:

  • Game Information: Game titles, Place IDs, and rating percentages from Roblox games you view while browsing Roblox.com
  • Browser Language: Your browser's language preference for localization purposes
  • Page Interaction Data: Information about which Roblox pages you visit (charts, home, discover) to apply appropriate filtering

User-Created Data:

  • Filter Lists: Custom filter lists you create, including game names and Place IDs you choose to filter
  • List Settings: Active/inactive list selections, filter modes (hide/blur/highlight), custom colors, and list configurations
  • User Preferences: UI visibility settings, panel collapse states, minimum/maximum rating thresholds, color preferences, and other locally stored non-personal settings related to the extension's interface or behavior
  • Performance Metrics (Optional): Operation timing data, normalized text cache statistics, and performance monitoring data – only collected if you enable the Performance Monitor feature

We do not collect, store, or access: Your Roblox account details, login credentials, passwords, or any personally identifiable information beyond what is necessary for filtering functionality.

Data Usage

The collected data is used exclusively for:

  • Applying user-defined filters to Roblox game listings
  • Matching games against your filter criteria (name matching, Place ID matching, rating-based filtering)
  • Displaying the extension interface in your preferred language
  • Remembering your UI preferences and filter settings across browsing sessions
  • Optimizing filter performance through text normalization caching
  • Monitoring extension performance (only if you enable the Performance Monitor)

We do not use this data for: Advertising, analytics for commercial purposes, profiling, or sharing with any third parties.

Data Storage Location and Type

All data is stored differently depending on the browser type:

Chromium-based browsers (e.g. Chrome, Edge, Brave, Opera)

  • chrome.storage.local: Filter lists, active lists, settings, UI state, custom filter modes, and performance metrics
  • chrome.storage.sync: Language preference only (synchronized across devices if you're signed into Chrome)

Firefox / Mozilla-based browsers

  • browser.storage.local: Filter lists, active lists, settings, UI state, custom filter modes, and performance metrics
  • browser.storage.sync: Language preference only (synchronized across devices if Firefox Sync is enabled)

Permissions Justification

  • storage: Required to save your filter lists, settings, and preferences locally on your device
  • unlimitedStorage: Allows storing comprehensive filter lists that may exceed the standard 5MB Chrome storage quota. Users who create extensive filter lists with thousands of entries may exceed standard limits. This permission ensures the extension can accommodate large community-shared filter lists and prevent data loss.

These permissions enable local storage only and do not grant access to data transmission or external connections.

How We Access Roblox.com

This extension operates only on specific Roblox.com pages you visit:

  • https://*.roblox.com/*charts*
  • https://*.roblox.com/*home*
  • https://*.roblox.com/*discover*

The extension reads game information displayed on these pages (such as titles, Place IDs, and ratings) to apply your selected filters. It modifies the visual presentation of games (for example, by hiding, blurring, or highlighting content) according to your filter settings. While the extension does not alter Roblox’s core functionality, it may interact with Roblox’s publicly available APIs to support filtering features. In such cases, basic technical information required to perform standard API requests may be transmitted to Roblox’s servers. No authentication tokens, passwords, or personal data are shared in this process.

APIs Accessed

To obtain publicly available game information and support filtering functionality, the extension may access the following Roblox API endpoints:

  • Games API: https://games.roblox.com/v1/games - used to retrieve basic details about games such as titles, descriptions.

These APIs are publicly available and do not require authentication. All requests are made in accordance with Roblox's public API usage policies.

File System Access

When you choose to export or import filter lists, the extension requests permission to save/load files to/from a directory you select. No files are read from or written to your system without your explicit action and permission.

Data Retention

Data is retained on your device until you:

  • Manually delete filter lists or settings within the extension
  • Clear your browser's extension storage
  • Uninstall the extension

Performance metrics stored locally are retained only for the duration of the active monitoring session and are automatically cleared when the performance panel is disabled, or the page is refreshed or closed. We do not retain any copies of your data on external servers. If you choose to export the metrics manually using the built-in JSON export feature, you are solely responsible for the handling and storage of the exported file.

Since all data is stored locally using Chrome/Firefox built-in storage mechanisms, security is managed by:

  • Your browser's storage encryption and security features

We implement input validation and sanitization to prevent malicious data injection. However, we are not responsible for unauthorized access to your device or data breaches caused by third-party software, hardware vulnerabilities, or compromised browser installations.
