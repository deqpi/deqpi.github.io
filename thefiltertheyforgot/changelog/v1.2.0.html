Version 1.2.0 Changelog

Released on September 17, 2025

Added

  • Added pre-baking of string normalization results in RAM, significantly reducing CPU load when dynamically handling long lists.
  • Added max rating filtering option.
  • Added the ability to select a filter color for lists.
  • Added plugin version information to the upper right corner of the panel.

Improved

  • Changed the plugin name in all available stores to The Filter They Forgot for Roblox to make it easier for new users to find the filter.
  • Changed the user interface to be more consistent, intuitive, and better suited for managing large numbers of lists.

Fixes

  • Fixed an issue with settings extending beyond the screen area; lists now automatically wrap within the allocated space.
  • Fixed a minor bug that caused the min rating filtering option to be set to false on first launch.

List

  • The base list has been updated from September 12, 2025, to September 17, 2025.
